# 通用排序与 Top N

单源方案和 source_steps[].query 均支持 order_by:[{field,direction}] 与 limit。direction 为 asc/desc，limit 为1至1000的整数。指定limit必须声明排序；排序只能引用该步骤实际输出的字段或指标，不能绕过字段权限。时间相同等情况应按已发布唯一键补充稳定排序；取N个实体需先明确去重或聚合粒度，不能把N条明细当作N个实体。

排序和数量进入需求确认、计划哈希、审批绑定以及Wren/本地编译。显式limit不会被中间完整性探测改成1001。没有显式limit时继续多读一行，截断则停止跨源后续查询；大小截断与行数策略仍生效，超过策略的Top N明确拒绝。

历史查询保留原方案，需重新分析才能生成新字段，不自动修改旧SQL或复用旧审批。该能力不新增文本评分或任意标量函数。
