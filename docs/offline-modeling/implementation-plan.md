# 离线建模扩展开发计划

本计划与 [架构设计](architecture.md)、[开发文档](development.md) 一起评审。阶段按可独立验收的结果安排。

| 阶段 | 开发内容 | 阶段验收 |
| --- | --- | --- |
| 0. 冻结边界与样例 | 确定独立目录、部署配置、文档事实契约和离线本体导出契约，准备脱敏测试资料 | 可独立启动扩展骨架，与在线 API 无内部代码依赖 |
| 1. 文档导入 | 支持 XLSX、DOCX、TXT、历史 SQL，多文件处理、分块、出处、精确检索和恢复 | 大文件逐块有处理结果，可跨段绑定口径与 SQL，可回读原文 |
| 2. DDL 与目录融合 | 按方言解析必传 DDL，绑定可选文档，做绑定预览、冲突和版本计算 | 仅 DDL 与 DDL 加文档均可产生标准目录，缺失或无效 DDL 返回错误，复合键完整，重复导入无重复记录 |
| 3. 关系分析与本体 | 声明提取及直接生效，补充发现、待确认、确认后发布扩展本体 | 显式映射直接发布，历史 JOIN 保留条件，基数明确时生效，基数未知时待确认。模型推断关系确认后生效 |
| 4. 页面与整体验收 | 加入离线导入入口、进度、目录查看和关系管理。接通人工新增、编辑、确认、停用与恢复 | 用户能从上传走到关联可用。导入后的文件和表目录受前后端共同保护，关系保存可立即反映在生效视图 |
| 5. 部署回归 | 验证独立启停，回归现有在线流程 | 扩展可独立运行与停用，导入和分析不会调用业务数据库，现有在线回归通过 |

DDL 基础验收覆盖 MySQL、PostgreSQL、Oracle 和 SQL Server，并用兼容语法样例覆盖所选国产数据库产品。厂商专有语法按客户真实导出样例扩展。格式识别中的 ER 图和 PDF 属于后续增量，建议优先收集标注清晰和难读连线各一类样例。现有调研工作簿可作为版式样例，规模验收另配有大量有效行及多个关系区域的资料。

## 关键验收用例

- 多 Sheet 的重复表头、跨区域字段记录、预留空行和公式错误。Word 跨章节解释与 TXT 历史 SQL 的关联。
- 声明关系位于文档末页，首次导入可以抽取。局部模型失败可恢复，前序结果复用。
- 文档和 DDL 的同名不同 Schema、约束矛盾、缺失字段及复合映射。导入完成后，补传文档和替换 DDL 均被拒绝。
- 大型 DDL 文件中的 `CREATE TABLE` 跨读取块，注释或字符串含分号，外键在后续语句添加或指向文件后部的表。验证语句边界、归并与续跑正确，超宽表的模型分片沿用同一表 ID。
- 同一测试结构的 DDL 解析和在线扫描产出可比较的标准目录。损坏或超限的结构语句有明确文件位置，导入失败不会创建可用数据源，同一批资料可续跑。
- 同一字段在不同角色或条件下引用不同对象。历史查询包含条件连接、CTE 和单表统计。
- 声明关系直接生效、纯推断待确认、冲突或映射不完整有明确原因。离线分析正常结束。
- 按指定方言解析 DDL。仅 DDL 和 DDL 加文档均可完成建模。
- 重复确认同一次导入不产生重复数据源。人工新增、编辑、确认、停用和恢复只修改关系。重新分析沿用原资料并保留人工决定，发布失败保留上一版关系。
- 扩展部署、停用和卸载只影响扩展入口与其拥有的资源。原在线关联、数据库探测和查询回归通过。

## 后续接入在线工作流

在文件抽取效果验收之后，在线适配器将扫描目录提交给绑定接口。关键词提取前补入相关业务说明和声明映射，查询生成前补入相关口径和历史案例。客户明确声明按声明来源管理，在线新推断继续采用现有验证策略。上线在线接入时单独验收旧任务、在线验证、跨源路径和扩展不可用时的行为。
