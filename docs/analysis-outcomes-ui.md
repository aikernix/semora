# 分析产出与技术诊断

工作台默认从已有事件提取有效产出，而不是把模型调用或心跳当成分析步骤。展示知识命中、知识原文、对象定义、关联路径、表结构、候选方案、实际修订差异、复核问题及解决情况、澄清和查询完成。重复的相同工具结果合并；零命中、请求开始、推理字符、耗时及重试不增加产出节点。

等待期间仅更新一条当前状态。产出卡片先显示简短结论，依据与变化可展开；技术诊断独立折叠，原始事件和审计继续保留。

新增 plan.candidate.validated 由服务端实际执行方案比较产生：说明文字变化不触发修订节点，前后变化不由模型编造。最多展示20处差异，超出时注明数量。校验成功仅是候选结构通过，不代表 Reviewer 或执行门禁通过。旧记录没有方案快照时不补造差异，仅展示已有可核验结果。
