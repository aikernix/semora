# 查询模型上下文的无损紧凑格式

仅在发送模型时编码，不改数据库本体、准备资料检查点、权限范围、SQL 编译和校验所用结构。需求、口径、全部已选字段、注释、枚举、约束、关系及来源均保留。

- 相同的 label 与 description 只发送一份，并提供位置引用。
- 本体字段与对应物理列合并，保留两套类型、不同属性及物理列原始顺序；多表投影无法明确映射时保持原表示。
- 对象数组使用列定义和数据行，减少重复 JSON 键；稀疏对象区分缺失与 null。
- 保留已有工具和输出契约。补充上下文工具使用相同编码，持久化检查点仍保存原始结构。
- 小资料若编码后更大，保留原格式。预算不变，不截断事实。

格式为 `query-material-tables-v1`，随资料提供解读说明；`decode_material` 用于自动验证完整可还原，不要求模型输出该格式。
